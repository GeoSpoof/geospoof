## (a) Chrome Web Store detailed description (plain text)

🛡️ 一鍵偽造地理位置、時區和所有位置訊號。

GeoSpoof 是一款重視隱私的 Chrome 擴充功能，可以偽造地理位置、變更你的位置。只要開啟一個開關，網站讀到的就是你選擇的偽造位置，而不是你真正所在的地方。

一般的位置變更工具只會移動地圖上的圖釘。GeoSpoof 更進一步：它會讓時區一致、阻擋 WebRTC IP 洩漏，並自動與你的 VPN 同步，讓每個訊號都符合你選擇的地點。

選擇城市、輸入確切座標，或讓 GeoSpoof 自動配合你的 VPN。隨時都能關閉，你的真實位置會原封不動地恢復。

🆕 2.3.0 新功能：「篩選」和「網站專屬位置」都支援網站群組、確切位址和來自連結的清單；新增「隨機化位置」；「網站」分頁和「設定」畫面也全新設計。

⭐ 為什麼大家選擇 GeoSpoof，而不是一般的位置變更工具

1️⃣ 一鍵設定偽造的 GPS 位置：任何城市或確切座標都可以。
2️⃣ 與 VPN 同步：偵測 VPN 的出口地區，並將你的位置設為該地區。
3️⃣ 背景自動同步：切換 VPN 伺服器後，你的位置會自動跟著更新。
4️⃣ 時區也一致：時鐘和日期與你的位置相符，兩者不會互相矛盾。
5️⃣ 阻擋 WebRTC 洩漏：即使使用 VPN，也能隱藏你的真實 IP。
6️⃣ 引擎層級偽造：由瀏覽器引擎套用時區，涵蓋背景 Worker 和跨網站框架，並盡可能提早生效。
7️⃣ 反指紋辨識：各項訊號保持一致，經得起真實指紋辨識指令碼所做的檢查。
8️⃣ 網站專屬位置：為特定網站設定專屬位置，其他網站則繼續使用你的主要位置。
9️⃣ 篩選：選擇「所有網站」、「允許清單」或「封鎖清單」，決定 GeoSpoof 在哪些網站運作。
🔟 不需帳號、不追蹤、不做分析：所有資料都留在你的裝置上。

📍 用你喜歡的方式設定偽造位置

▸ 依城市或地址搜尋，直接找到確切地點。
▸ 手動輸入精確的緯度和經度，取得乾淨的 GPS 定位。
▸ 調整準確度，從「擬真」到自訂的公尺數值都可以。
▸ 最多可儲存 50 個收藏地點，點一下就能切換。
▸ 「設定」（⚙ 齒輪圖示）現在會先列出網站看到的內容，下方則是「進階」和「一般」選項。

🎲 隨機化位置

網站可以取得你所選位置附近的隨機地點，而不是確切的地點：範圍可選 0.5 公里、2 公里或 10 公里以內。你可以一直使用同一個地點，也可以在每個瀏覽器工作階段、每小時或每天選取新地點。

隨機地點一律以你在 GeoSpoof 中選擇的位置為中心，絕不會以你的真實位置為中心；時區也仍然跟著你選擇的位置。有一個取捨要知道：會變動的地點比較難在多次造訪之間被認出來，但收集到多個地點的網站可以把它們平均。

🧭 逐一決定要在哪些網站運作

全新設計的「網站」分頁會顯示你目前所在的網站和它看到的位置，只要一個按鈕就能把它加入清單或從清單移除。

▸ 篩選：在「篩選模式」中選擇「所有網站」、「允許清單」（只在你列出的網站運作）或「封鎖清單」（除了你列出的網站以外都運作）。
▸ 網站專屬位置：例如讓 Twitch 看到墨西哥城、ChatGPT 看到都柏林，其他網站則看到東京。多個項目同時符合時，以最明確的那一個為準。
▸ 網站群組：一個項目就涵蓋某項服務使用的所有網域，例如 Google、Netflix 或 OpenAI，也可以是「中國網站」這類地區群組。約 1,500 個群組來自代理工具稱為 geosite 的 v2fly 網域清單，GeoSpoof 大約每週更新一次。
▸ 僅限確切位址：只符合 mail.example.com，不包含它的子網域。
▸ 來自連結的清單：貼上你的代理工具已在使用的網域清單 https:// 連結，GeoSpoof 會下載它並每週更新。

網站群組、確切位址和來自連結的清單，在「篩選」和「網站專屬位置」中都能使用。

🌍 不論有沒有 VPN，都能偽造地理位置

VPN 會變更你的 IP。GeoSpoof 則會改寫瀏覽器透過地理位置 API 回報的座標，還能讓兩者同步。

可以單獨使用，也可以搭配 VPN，讓你的 IP、位置和時區彼此吻合。

🔒 隱私優先

🔹 所有處理都在你的裝置上進行，GeoSpoof 絕不會將你的真實位置傳送到伺服器。
🔹 不需帳號、不追蹤、不做分析。設定都儲存在本機。
🔹 你的篩選清單和網站專屬位置都不會離開你的裝置。更新網站群組時會下載整份目錄，因此任何請求都不會透露你選了哪些群組。
🔹 來自連結的清單會直接從存放它的網站下載，該網站會看到你的 IP 位址，跟任何下載一樣。
🔹 開放原始碼：可以在 GitHub 上檢視它的實際運作方式。
🔹 關閉保護後，你的真實座標會原封不動地恢復。

💡 適合哪些人

◆ 注重隱私、不希望網站記錄自己所在位置的人。
◆ 測試位置、時區和地區功能的開發人員。
◆ 需要存取特定地區內容和服務的人。
◆ 希望瀏覽器位置與 VPN 出口節點一致的 VPN 使用者。

❓ 常見問題

📌 網站還會看到我的真實位置嗎？
💡 不會。保護開啟時，瀏覽器會回傳你選擇的地點。

📌 這是 VPN 嗎？
💡 不是。GeoSpoof 變更的是瀏覽器回報的座標，而不是你的 IP。它很適合搭配 VPN 使用，甚至能自動與 VPN 同步。

📌 可以設定確切的位置嗎？
💡 可以。輸入精確的緯度和經度，或搜尋城市，就能乾淨地偽造 GPS。

📌 它也會變更我的時區嗎？
💡 會。GeoSpoof 會同時偽造你的時區和位置，讓兩者始終相符；只變更位置的工具常常在這裡露出破綻。

📌 這只是位置變更工具嗎？
💡 不只如此。GeoSpoof 會設定偽造位置，同時讓時區一致並阻擋 WebRTC 洩漏，避免任何訊號與它矛盾。

📌 可以在 Google 地圖上使用嗎？
💡 可以。GeoSpoof 適用於任何使用瀏覽器地理位置 API 的網站。

📌 我的資料安全嗎？
💡 安全。GeoSpoof 在本機執行、不收集任何資料，而且是開放原始碼。與你位置有關的資訊都不會離開你的裝置。

📌 網站專屬位置會變更我的 IP 或帳號所屬的地區嗎？
💡 不會。它變更的是該網站的頁面從瀏覽器讀到的內容：位置、時區，以及你設定語言跟隨位置時的語言。你的 IP 和帳號資料不會改變；想要最一致的結果，請搭配同一地點的 VPN 出口。

📌 網站看得出我在使用 GeoSpoof 嗎？
💡 無法完全排除。GeoSpoof 能通過真實指紋辨識指令碼所做的檢查，並讓各項訊號保持一致，但沒有任何擴充功能能抹去所有痕跡：引擎內部機制和時序旁路攻擊都超出擴充功能能處理的範圍。你可以到 geospoof.com/test 親自檢查。

📌 需要註冊嗎？
💡 不需要帳號，也不用設定。安裝後就能立即變更你的位置。

📲 現在也支援 iPhone、iPad 和 Mac。

在 Chrome 中，網站專屬位置、網站群組和隨機化位置都是免費的。在 Safari 中，篩選、網站專屬位置和隨機化位置屬於 GeoSpoof Pro 功能，網站群組、確切位址和來自連結的清單則尚未提供。

安裝 GeoSpoof，設定偽造位置，自己決定網路能看到你在哪裡。

在 Firefox 中，網站專屬位置、網站群組和隨機化位置都是免費的。在 Safari 中，篩選、網站專屬位置和隨機化位置屬於 GeoSpoof Pro 功能，網站群組、確切位址和來自連結的清單則尚未提供。

安裝 GeoSpoof，設定偽造位置，自己決定網路能看到你在哪裡。
