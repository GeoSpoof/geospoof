## (a) Chrome Web Store detailed description (plain text)

🛡️ 位置情報もタイムゾーンも、あらゆる位置のシグナルをワンクリックで偽装。

GeoSpoof は、プライバシーを第一に考えた Chrome 用の位置情報偽装・位置変更ツールです。スイッチをひとつ入れるだけで、どのサイトにも本当の居場所ではなく、あなたが選んだ偽の位置が伝わります。

ふつうの位置変更ツールは地図上のピンを動かすだけです。GeoSpoof はタイムゾーンを合わせ、WebRTC による IP 漏洩をブロックし、VPN と自動で同期するので、すべてのシグナルが選んだ場所と一致します。

都市を選ぶ、正確な座標を入力する、または VPN に自動で合わせる。いつでもオフにでき、オフにすれば本当の位置がそのまま戻ります。

🆕 2.3.0 の新機能：「フィルター」と「サイト別の位置」で、サイトグループ、このアドレスのみ、リンク先のリストが使えるようになりました。「位置をランダム化」も追加し、「サイト」タブと「設定」画面のデザインも一新しました。

⭐ ふつうの位置変更ツールではなく GeoSpoof が選ばれる理由

1️⃣ ワンクリックで偽の GPS 位置を設定：どの都市でも、正確な座標でも。
2️⃣ VPN と同期：VPN の出口地域を検出し、位置をそこに合わせます。
3️⃣ バックグラウンド自動同期：VPN サーバーを切り替えると、位置も自動で追従します。
4️⃣ タイムゾーンも一致：時計と日付が位置と合うので、両者が食い違いません。
5️⃣ WebRTC 漏洩をブロック：VPN 使用中でも本当の IP を隠します。
6️⃣ エンジンレベルのなりすまし：ブラウザのエンジン自体がタイムゾーンを適用し、Worker やクロスサイトのフレームにも、Chrome が許す限り早い段階から効きます。
7️⃣ フィンガープリント対策：すべてのシグナルの整合性を保ち、実際のフィンガープリントスクリプトが行うチェックにも耐えます。
8️⃣ サイト別の位置：特定のサイトにだけ別の位置を設定し、ほかのサイトはメインの位置のままにできます。
9️⃣ フィルター：「すべてのサイト」「許可リスト」「拒否リスト」から選び、GeoSpoof を働かせるサイトを決められます。
🔟 アカウント不要、追跡なし、分析なし：すべてあなたのデバイスの中で完結します。

📍 偽の位置は好きな方法で設定

▸ 都市名や住所で検索して、その場所にぴったり合わせられます。
▸ 緯度と経度を手で正確に入力して、きれいな GPS 位置に。
▸ 精度はリアルな値から、メートル単位の任意の値まで調整できます。
▸ お気に入りの場所を最大 50 件保存して、タップひとつで切り替え。
▸ 「設定」（⚙ ギア）は、サイトに見える情報を先頭に、その下に「詳細設定」と「一般」をまとめました。

🎲 位置をランダム化

サイトには、選んだ場所そのものではなく、その周辺のランダムな地点を伝えられます。範囲は 0.5 km以内、2 km以内、10 km以内から選べます。同じ地点を使い続けることも、ブラウザのセッションごと、1時間ごと、1日ごとに新しい地点を選ぶこともできます。

地点はいつも GeoSpoof で選んだ位置を中心に選ばれ、本当の位置を中心にすることはありません。タイムゾーンも選んだ位置に合わせたままです。知っておきたいトレードオフがひとつあります。地点が変わると訪問をまたいで同一人物だと気づかれにくくなりますが、複数の地点を集めたサイトはそれらを平均できます。

🧭 どのサイトで働かせるかを、サイトごとに

新しくなった「サイト」タブには、いま開いているサイトと、そのサイトに見えている位置が表示され、ボタンひとつでリストに追加したり外したりできます。

▸ フィルター：「フィルターモード」で「すべてのサイト」、「許可リスト」（リストにあるサイトだけ）、「拒否リスト」（リストにあるサイト以外すべて）から選べます。
▸ サイト別の位置：たとえば Twitch にはメキシコシティ、ChatGPT にはダブリンを見せ、ほかのサイトには東京を見せられます。複数のエントリーが当てはまるときは、いちばん具体的なものが優先されます。
▸ サイトグループ：ひとつのエントリーで、Google、Netflix、OpenAI などのサービスが使うすべてのドメインや、「中国のサイト」のような地域をまとめて指定できます。約 1,500 のグループは、プロキシツールで geosite と呼ばれる v2fly のドメインリストに基づいており、GeoSpoof がおよそ週に 1 回更新します。
▸ このアドレスのみ：mail.example.com だけに一致させ、そのサブドメインは含めません。
▸ リンク先のリスト：プロキシで使っているドメインリストの https:// リンクを貼り付けると、GeoSpoof がダウンロードして毎週更新します。

サイトグループ、このアドレスのみ、リンク先のリストは、「フィルター」と「サイト別の位置」のどちらでも使えます。

🌍 VPN があってもなくても位置情報を偽装

VPN が変えるのは IP です。GeoSpoof は、ブラウザが位置情報 API を通じて伝える座標を書き換え、さらに両者を同期させることもできます。

単体で使っても、VPN と組み合わせても OK。IP、位置、タイムゾーンのつじつまがそろいます。

🔒 プライバシー最優先

🔹 処理はすべてデバイス上で行われ、GeoSpoof が本当の位置をサーバーに送ることはありません。
🔹 アカウント不要、追跡なし、分析なし。設定はローカルに保存されます。
🔹 フィルターとサイト別の位置がデバイスの外に出ることはありません。サイトグループの更新ではカタログ全体をダウンロードするので、どのグループを選んだかがリクエストから知られることはありません。
🔹 リンク先のリストは、そのファイルを置いているサイトから直接ダウンロードされます。ふつうのダウンロードと同じく、そのサイトにはあなたの IP アドレスが見えます。
🔹 オープンソース：何をしているかを GitHub でそのまま確認できます。
🔹 保護をオフにすれば、本当の座標がそのまま戻ります。

💡 こんな方におすすめ

◆ サイトに居場所を記録されたくない、プライバシーを大切にする方。
◆ 位置、タイムゾーン、地域ごとの機能をテストする開発者。
◆ 地域限定のコンテンツやサービスを利用したい方。
◆ ブラウザの位置を VPN の出口ノードと一致させたい VPN ユーザー。

❓ よくある質問

📌 サイトに本当の位置は見えてしまいますか？
💡 いいえ。保護がオンの間、ブラウザはあなたが選んだ場所を返します。

📌 これは VPN ですか？
💡 いいえ。GeoSpoof が変えるのはブラウザが伝える座標で、IP ではありません。VPN との相性は抜群で、VPN と自動で同期することもできます。

📌 正確な地点を指定できますか？
💡 はい。緯度と経度を正確に入力するか、都市を検索すれば、きれいに GPS を偽装できます。

📌 タイムゾーンも変わりますか？
💡 はい。GeoSpoof は位置と一緒にタイムゾーンも偽装するので、両者は常に一致します。位置だけを変えるツールでは、ここでぼろが出がちです。

📌 ただの位置変更ツールですか？
💡 それだけではありません。GeoSpoof は偽の位置を設定したうえで、タイムゾーンを合わせ、WebRTC 漏洩もブロックするので、位置と矛盾するシグナルが残りません。

📌 Google マップでも使えますか？
💡 はい。ブラウザの位置情報 API を使うサイトなら、どこでも使えます。

📌 データは安全ですか？
💡 はい。GeoSpoof はローカルで動作し、何も収集せず、オープンソースです。位置に関する情報がデバイスの外に出ることはありません。

📌 サイト別の位置で、IP やアカウントの地域も変わりますか？
💡 いいえ。変わるのは、そのサイトのページがブラウザから読み取る情報、つまり位置、タイムゾーン、そして言語を位置に合わせる設定にしている場合は言語です。IP やアカウント情報は変わらないので、いちばん一貫した結果を得るには、同じ場所の VPN 出口と組み合わせてください。

📌 GeoSpoof を使っていることはサイトにわかりますか？
💡 絶対にわからないとは言えません。GeoSpoof は実際のフィンガープリントスクリプトが行うチェックをかわし、すべてのシグナルの整合性を保ちますが、どの拡張機能もすべての痕跡は消せません。エンジン内部の仕組みやタイミングのサイドチャネルは、拡張機能の手が届かない領域です。geospoof.com/test でご自身で確かめられます。

📌 登録は必要ですか？
💡 アカウントも初期設定も不要です。インストールしたらすぐに位置を変えられます。

📲 iPhone、iPad、Mac にも対応しました。

Chrome では、サイト別の位置、サイトグループ、位置をランダム化はすべて無料です。Safari では、フィルター、サイト別の位置、位置をランダム化は GeoSpoof Pro の機能で、サイトグループ、このアドレスのみ、リンク先のリストはまだ使えません。

GeoSpoof をインストールして偽の位置を設定し、ウェブにどこまで居場所を見せるかを自分で決めましょう。

リンク：
— geospoof.com

Firefox では、サイト別の位置、サイトグループ、位置をランダム化はすべて無料です。Safari では、フィルター、サイト別の位置、位置をランダム化は GeoSpoof Pro の機能で、サイトグループ、このアドレスのみ、リンク先のリストはまだ使えません。

GeoSpoof をインストールして偽の位置を設定し、ウェブにどこまで居場所を見せるかを自分で決めましょう。
