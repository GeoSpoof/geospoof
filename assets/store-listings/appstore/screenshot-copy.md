# App Store Screenshot Copy — GeoSpoof (iOS / iPadOS)

Text burned into the images in `appstore/ios/` and `appstore/ipados/`.
`/` marks the intended line break.

SS3–SS5 are set in ALL CAPS, so the casing below doesn't matter for those three —
don't "fix" the lowercase adjectives. Three things that do matter when capping:

- **Keep every diacritic.** `OÙ` without the accent becomes `OU` ("or"), which
  changes the meaning. Same for `FÁCIL`, `PRIVÉ`, `WÄHLEN`, `VÄLJ`.
- **Test-render Vietnamese.** `DỄ DÀNG`, `CHỌN BẤT CỨ ĐÂU`, `LỌC TRANG WEB` stack
  a tone mark and a dot on one letter; many display fonts clip them at cap height.
- **ja/zh have no caps.** Match weight instead of case. SS5 `ja` uses 簡単 rather
  than かんたん for that reason — hiragana reads light next to all-caps Latin.

Caps run ~10% wider than mixed case at the same point size, which is worth
remembering when a line feels tight.
