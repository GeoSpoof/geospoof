## (a) Chrome Web Store detailed description (plain text)

🛡️ 一键伪造地理位置、时区和所有位置信号。

GeoSpoof 是一款注重隐私的 Chrome 扩展程序，用于伪造地理位置、更改你的位置。只需打开一个开关，网站读取到的就是你选择的虚拟位置，而不是你的真实所在地。

普通的位置修改工具只会移动地图上的图钉。GeoSpoof 做得更多：它会同步调整时区、阻止 WebRTC IP 泄漏，并自动与你的 VPN 同步，让每个信号都与你选择的地点一致。

选择一个城市、输入精确坐标，或者让 GeoSpoof 自动匹配你的 VPN。随时可以关闭，你的真实位置会原样恢复。

🆕 2.3.0 新功能：“筛选”和“网站专属位置”都支持网站组、确切地址和来自链接的列表；新增“随机化位置”；“网站”标签页和“设置”界面也经过了重新设计。

⭐ 为什么大家选择 GeoSpoof，而不是普通的位置修改工具

1️⃣ 一键设置虚拟 GPS 位置：任意城市或精确坐标都可以。
2️⃣ 与 VPN 同步：检测 VPN 的出口地区，并把你的位置设为该地区。
3️⃣ 后台自动同步：切换 VPN 服务器后，你的位置会自动跟着变化。
4️⃣ 时区同样一致：时钟和日期与你的位置相符，两者不会互相矛盾。
5️⃣ 阻止 WebRTC 泄漏：即使在 VPN 之下，也能隐藏你的真实 IP。
6️⃣ 引擎级伪造：由浏览器引擎应用你的时区，覆盖 Worker 和跨站框架，并在 Chrome 允许的最早时机生效。
7️⃣ 反指纹识别：所有信号保持一致，经得起真实指纹脚本所做的检测。
8️⃣ 网站专属位置：为某个网站设置专属位置，其他网站继续使用你的主位置。
9️⃣ 筛选：选择“所有网站”、“允许列表”或“拒绝列表”，决定 GeoSpoof 在哪些网站上生效。
🔟 无需账号、不跟踪、不做分析：所有数据都留在你的设备上。

📍 用你喜欢的方式设置虚拟位置

▸ 按城市或地址搜索，直接定位到具体地点。
▸ 手动输入精确的纬度和经度，获得干净的 GPS 定位。
▸ 调整精度，从“逼真”到自定义的米数都可以。
▸ 最多收藏 50 个地点，轻点一下即可切换。
▸ “设置”（⚙ 齿轮图标）现在把网站看到的内容放在最前面，下面是“高级”和“通用”选项。

🎲 随机化位置

网站可以获得你所选位置附近的一个随机点，而不是精确的地点：范围为 0.5 公里、2 公里或 10 公里以内。你可以一直使用同一个点，也可以在每次浏览器会话、每小时或每天选取一个新点。

随机点始终围绕你在 GeoSpoof 中选择的位置生成，绝不会围绕你的真实位置；时区也仍然跟随你选择的位置。需要了解一个取舍：不断变化的点更难在多次访问之间被认出，但收集到多个点的网站可以对它们取平均值。

🧭 逐个决定在哪些网站上生效

重新设计的“网站”标签页会显示你当前所在的网站以及它看到的位置，一个按钮就能把它加入列表或从列表中移除。

▸ 筛选：在“筛选模式”中选择“所有网站”、“允许列表”（只在你列出的网站上生效）或“拒绝列表”（除你列出的网站外都生效）。
▸ 网站专属位置：比如让 Twitch 看到墨西哥城、ChatGPT 看到都柏林，其他网站都看到东京。多个条目同时匹配时，以最具体的那一个为准。
▸ 网站组：一个条目就能覆盖某项服务使用的全部域名，例如 Google、Netflix 或 OpenAI，也可以是“中国网站”这样的地区分组。约 1,500 个网站组来自 v2fly 域名列表，也就是代理工具所说的 geosite，GeoSpoof 大约每周更新一次。
▸ 仅限确切地址：只匹配 mail.example.com，不包括它的子域名。
▸ 来自链接的列表：粘贴你的代理工具已经在用的域名列表 https:// 链接，GeoSpoof 会下载它并每周更新。

网站组、确切地址和来自链接的列表在“筛选”和“网站专属位置”中都可以使用。

🌍 无论是否使用 VPN，都能伪造地理位置

VPN 改变的是你的 IP。GeoSpoof 改写的是浏览器通过地理位置 API 报告的坐标，并且可以让两者保持同步。

可以单独使用，也可以和 VPN 搭配，让你的 IP、位置和时区说法一致。

🔒 隐私优先

🔹 所有处理都在你的设备上完成，GeoSpoof 从不把你的真实位置发送到服务器。
🔹 无需账号、不跟踪、不做分析。设置都保存在本地。
🔹 你的筛选列表和网站专属位置都不会离开你的设备。更新网站组时会下载完整目录，因此任何请求都不会透露你选了哪些网站组。
🔹 来自链接的列表直接从托管它的网站下载，和任何下载一样，该网站会看到你的 IP 地址。
🔹 开源：可以在 GitHub 上查看它到底做了什么。
🔹 关闭保护后，你的真实坐标会原样恢复。

💡 适合哪些人

◆ 注重隐私、不希望网站记录自己所在位置的人。
◆ 测试位置、时区和地区功能的开发者。
◆ 需要访问特定地区内容和服务的人。
◆ 希望浏览器位置与 VPN 出口节点一致的 VPN 用户。

❓ 常见问题

📌 网站还会看到我的真实位置吗？
💡 不会。保护开启时，浏览器返回的是你选择的地点。

📌 这是 VPN 吗？
💡 不是。GeoSpoof 改变的是浏览器报告的坐标，而不是你的 IP。它非常适合与 VPN 搭配使用，甚至可以自动与 VPN 同步。

📌 可以设置一个精确的点吗？
💡 可以。输入精确的纬度和经度，或者搜索城市，就能干净地伪造 GPS。

📌 它也会更改我的时区吗？
💡 会。GeoSpoof 会同时伪造你的时区和位置，让两者始终一致；只改位置的工具往往在这里露出破绽。

📌 它只是一个位置修改工具吗？
💡 不止如此。GeoSpoof 设置虚拟位置之后，还会匹配你的时区并阻止 WebRTC 泄漏，不让任何信号与之矛盾。

📌 能在 Google 地图上使用吗？
💡 能。GeoSpoof 适用于所有使用浏览器地理位置 API 的网站。

📌 我的数据安全吗？
💡 安全。GeoSpoof 在本地运行、不收集任何数据，而且是开源的。与你位置有关的信息都不会离开你的设备。

📌 网站专属位置会改变我的 IP 或账号所在地区吗？
💡 不会。它改变的是该网站页面从浏览器读取到的内容：位置、时区，以及在你设置语言跟随位置时的语言。你的 IP 和账号信息保持不变；想要最一致的效果，请搭配同一地点的 VPN 出口。

📌 网站能看出我在使用 GeoSpoof 吗？
💡 无法完全排除。GeoSpoof 能通过真实指纹脚本所做的检测，并让所有信号保持一致，但没有任何扩展程序能抹去所有痕迹：引擎内部机制和计时侧信道都超出了扩展程序的能力范围。你可以在 geospoof.com/test 亲自检查。

📌 需要注册吗？
💡 无需账号，也无需设置。安装后即可立即更改你的位置。

📲 现已支持 iPhone、iPad 和 Mac。

在 Chrome 中，网站专属位置、网站组和随机化位置都是免费的。在 Safari 中，筛选、网站专属位置和随机化位置属于 GeoSpoof Pro 功能，网站组、确切地址和来自链接的列表暂未提供。

安装 GeoSpoof，设置虚拟位置，由你决定网络能看到你在哪里。
